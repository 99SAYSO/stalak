# Demande du Chef de projet : partenariat avec 12Thousand (26/11/2026)

12Thousand (YouTube @TwelveThous) est américain et fait des conseils pour rappeurs underground.
- 6 030 abonnés, environ 20 000 vues par semaine, et une communauté Skool.
- C'est le premier créateur-conseiller (`docs/marketing/PROMESSE.md`, `chef-test-acquisition-payante.md`).
- Offre validée par le propriétaire le 26/11 à 0 h 09.
- Le propriétaire envoie lui-même les messages et paie lui-même.

## L'offre
- **50 % de chaque paiement** des abonnés venus de lui (lien `?ref=12k` ou code `12K`), **pendant 12 mois** à partir de leur 1er paiement. Versé chaque mois, sur les paiements encaissés, hors remboursements.
- **Code `12K`** : **-50 % sur le 1er mois** pour son public.
- **Creator Plus gratuit pour lui**, sans limite de durée tant que le partenariat dure.
- **Bonus de 50 $ au 10e abonné payant.**
- Plus tard, si ça marche : un style de montage « 12K cut » (à cadrer avec App, pas maintenant).

## Ce qu'on lui demande, sur 3 mois
- **3 passages** de 60 à 90 s dans ses vidéos YouTube, **un par mois**. Sur son propre son : d'abord le snippet en une prise, puis la version Stalak.
- Le **lien et le code dans la description** de ses vidéos pendant les 3 mois.
- **1 post dans son Skool**, plus un **« défi snippet »** : ses membres font un snippet avec Stalak, et il montre le meilleur dans une vidéo.
- La mention #ad, et ses retours sur l'app.
- **Bilan à 3 mois** avec les chiffres : on continue, on élargit, ou on arrête. Les 50 % restent dus 12 mois sur les abonnés déjà amenés.

## Comptes
1. Lui activer un Creator Plus gratuit dès que le propriétaire donne son adresse e-mail (pas de facture Paddle, comme `keep_plan`).
2. Créer le code `12K` dans Paddle (-50 % sur le 1er paiement mensuel, Pro et Creator Plus). Garder sur le compte la source `ref:12k` ou `code:12K`, jusqu'au paiement.
3. Tableau de bord : une carte « Partenaires » pour 12k avec les visites, les inscrits, les abonnés, les paiements encaissés, ce qu'on lui doit (50 % sur 12 mois) et le bonus des 10 abonnés.
4. Ensuite, une page privée pour lui avec les mêmes chiffres (lien secret, sans données personnelles des abonnés).

Compte rendu : `docs/handoff/compte-partenariat-12k.md`.

## Juridique
- De courtes conditions de partenariat (EN) : commission, durée, paiement mensuel, remboursements exclus, interdiction du spam et des fausses promesses (« percer », nombre de vues), mention #ad (FTC), et fin du partenariat possible à tout moment.
- Une ligne sur les codes partenaires dans les conditions de vente (FR/EN).

Compte rendu : `docs/handoff/legal-partenariat-12k.md`.
