# Comptes rendus pour le Chef de projet

Chaque conversation écrit ici, sur sa branche, un fichier `<nom-de-la-branche-avec-des-tirets>.md`
(exemple : `marketing-audit-site.md` pour la branche `marketing/audit-site`) :

```
Statut : PRÊT            (ou EN COURS)
Branche : marketing/audit-site
Résumé : …
Fichiers touchés : …
Migration SQL : aucune (ou le SQL complet)
Tests : …
Reste au propriétaire : …
```

Puis elle pousse la branche sur GitHub. Le Chef de projet la repère tout seul, la relit, la teste, la fusionne et la met en ligne.
